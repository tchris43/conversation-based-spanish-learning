The idea for my project is to build a language learning app for learning spanish. It will improve on existing apps like duo-lingo by keeping track of the user's progress. It will know what words they have learned, what phrases they have learned, what concepts they struggle on, and it will be able to use spaced review to help them achieve mastery. It will focus on getting them conversationally fluent through practice rather than drilling in grammar rules to get it perfect on paper. It will use prompt engineering to design how to interact with the user. It will use context management by injecting the progress of the user into each session, and it will use tool calling to look up vocab and other things as necessary.
