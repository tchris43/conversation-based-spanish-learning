Use this skill anytime an agent needs to edit or implement UI design.

UI rules:
- Keep the UI as minimalistic as possible.
- Use Gradio unless the user explicitly says otherwise.
- Do not add more boxes, panels, or visual sections than the absolute minimum necessary.
- The UI should still be visually appealing.
- The visual direction should give off Spanish fiesta vibes.

When applying this skill:
- Prefer a small number of well-chosen interface elements over feature-heavy layouts.
- Keep the design simple enough that the core interaction is immediately obvious.
- Use color, typography, spacing, and small decorative touches to create the Spanish fiesta feeling without adding unnecessary structure.
