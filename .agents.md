Run `myteam get role` at startup so you can load the default role instructions for this repository.

Treat the returned role instructions as first-class instructions for how to operate in this repo.

The default role is the main orchestration agent. It is responsible for:
- planning components
- making design decisions
- debugging system behavior
- kicking off subagents when tasks should be delegated

When you delegate work to a subagent, tell that subagent to run `myteam get role <role>` with its assigned role so it can load its own instructions before starting work.
