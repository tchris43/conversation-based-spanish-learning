1. Onboarding Form (first visit)

Inputs

Goal, topic preference, weekly time, self-rating.

Outputs

Seeded profile (local storage) plus confirmation prompt.

Questions

Required fields? Confirmation path? Should onboarding summary log?

↓

2. Practice Loop

Scheduler

Runs spaced-review algorithm, returns prioritized review set + new item.

Prompt

Current topic, goals, review/new items, learner message, inline guidance.

LLM Response

Correction, rationale, next action in structured JSON (“Correction”, “Rationale”, “Nextt”).

Updates

Update exposures/correctness, store “needs work” evidence + rationale, refresh scheduler metadata.

Inline Hint

Display correction cue, keep conversation flowing, do not block user input.

Fallback

If rationale fails heuristic, trigger clarification prompt (“cite the turn”).

↓

3. Logs & Diagnostics

Collapsible sidebar surfaces prompt/response pairs, “needs work” insights, and evidence. Read-only during MVP, aggregated for future drills.

Prompt

Topic + profile summary + latest user message.

LLM

Structured JSON (Correction/Rationale/Nextt) + timing.

Needs Work

Evidence phrase, rationale, timestamp, status.

Control Flow Questions

  • When does the scheduler run vs. when do we hit the LLM?
  • How do we surface inline hints without blocking the next turn?
  • What triggers the “cite the turn” clarification and how often?
  • How are logs grouped and filtered in the sidebar?
