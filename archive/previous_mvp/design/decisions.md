# Design Decisions

Every entry here documents an open question from `design/open_questions.md`. Follow the structure below so the decision stands out and the alternatives + rationale stay short:

### Question 1 – [Insert question text]
- **Decision:** …
- Options considered: …
- Rationale: …

When we resolve a question, add a new section with the number, the question text, the bolded decision, and a quick rationale. Keep prose concise so the list stays scannable.
