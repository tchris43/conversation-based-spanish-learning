## Overview
My wife served Spanish Speaking and I served Japanese speaking. Therfore, it has become a goal of mine to learn Spanish. However, the current apps are pretty much Duolingo, and Spanish Dictionary. Both of which seem to not be the most effective learning process, and can be boring at times. I thought that practicing through conversation is the best way. So, I decided that I would build an app that uses conversation to help you learn Spanish while keeping track of the words you know and your goals so that it can help you continually progress.

## Agentic Principles
This project included prompt engineering, multi-agent-systems, tool calls, audio, and context management. The bulk of it was prompt engineering because I had about 9 different major agents that I had to prompt, and it was tricky but I went through dozens of iterations for the first few. Trying to figure out how to get the AI to respond like a conversation partner rather than a helpful agent was a lot harder than I thought it would be. It was also very difficult to get it to the point where it would adjust to the user's level of difficulty. The multi-agent system started with an onboarding agent that got the user's goal so it could make a scenario and then passed that scenario to the conversation agent to practice with the user and then the assessment agent scored the conversation and passed a summary to a gameplan agent which then made a road map and then a module generator created the scenario for a module, a session agent talked to the user in the module, and a final concluder agent managed the spaced-review. The tool calls were for things like correcting the user or other things like that. I used context management to input the spaced review for that day into every LLM call so that it could use those words.

## More Takeaways
I learned how difficult it is to get an agent to consitently output what you want it to, and to handoff to the other agents and to call tools when you want it to. You have to be so clear and direct. I learned that codex makes it a lot easier to do a lot of the code plumbing. I spent most of my time prompt engineering and telling codex what tools it needed to make and connect to everything so that I could just focus on the prompt engineering. I used codex to help with the plubming for the multi-agent system and the context management. I didn't want codex to write the prompts because I wanted the practice, but also I felt like those were the most important things to get right. I didn't want codex to make any assumptions. I was surprised how easy it was to implement audio.

So the onboarding chat is not bad, but the roadmap could use some work. The best part is probably how natural the first conversation is, but it was hard to think of a good way to assess level and make a roadmap. If I could go back, I would start with a clearer vision of what I was trying to produce. I really didn't know what direction I was trying to go.
